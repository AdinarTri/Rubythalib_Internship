📄 Dokumentasi API — Flask

Base URL: http://127.0.0.1:5000 · ← Kembali ke Dashboard

POST/api/grayscale

Konversi gambar menjadi grayscale.

Body (form-data)TipeKeterangan
fileFileWajib. File gambar (jpg/png/bmp/dll).

Response: image/png (200) atau {"error": "..."} (400).

POST/api/split-channels

Memisahkan gambar menjadi channel Blue, Green, Red — digabung berdampingan dalam satu gambar output.

Body (form-data)TipeKeterangan
fileFileWajib. File gambar.

Response: image/png (200) atau {"error": "..."} (400).

POST/api/crop

Memotong gambar sesuai koordinat dan ukuran.

ParameterTipeDefaultKeterangan
fileFile (form-data)—Wajib. File gambar.
xint (query/form)0Koordinat X titik awal crop.
yint (query/form)0Koordinat Y titik awal crop.
widthint (query/form)100Lebar area crop.
heightint (query/form)100Tinggi area crop.

Contoh: POST /api/crop?x=10&y=10&width=300&height=200

Response: image/png (200) atau {"error": "..."} (400).

POST/api/line-detection

Mendeteksi garis menggunakan Canny edge detection + Probabilistic Hough Transform. Garis digambar merah di atas gambar asli.

ParameterTipeDefaultKeterangan
fileFile (form-data)—Wajib. File gambar.
canny_lowint (query/form)50Threshold bawah Canny edge detector.
canny_highint (query/form)150Threshold atas Canny edge detector.
hough_thresholdint (query/form)100Minimal vote agar garis dianggap terdeteksi.

Response: image/png (200) atau {"error": "..."} (400).
